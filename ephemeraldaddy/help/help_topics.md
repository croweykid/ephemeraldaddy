# Help Topics

## Where did my Observations / Subjective Notes go?! :: Help! Panels are missing!
Did you enable "Private mode" in Settings, per chance? In the app menu try Ephemeral Daddy>Settings>Developer Tools>look for "Private Mode" and see if it's checked. If so, uncheck it. Your Observations / Subjective Notes panel will come back!

Alternately, see if you've hidden the missing modules in Settings>Show/Hide Modules.

Or, if you've reinstalled the app from scratch, it may have restored the default settings, in which case you'll need to go into Settings and re-enable the visibility of whatever you are looking for. Most of these can be found in Show/Hide Modules or Developer Tools.
